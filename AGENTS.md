# Acme agent guide

When shaping, building, reviewing or hardening anything a user sees in Acme, load `design-skill/SKILL.md` (or `.claude/skills/design-skill/SKILL.md` if installed there).

Applies to:

- pages, components and controls
- copy, interaction, accessibility, responsive behaviour and states
- design reviews from a URL, screenshot or diff

Skip:

- backend work with no visible effect
- tests, scripts and generated files with no UI change
- docs that are not product copy

Before editing user-facing strings or markdown guidance, load `writing-docs/SKILL.md`.

When you verify or review UI, report which skill files you loaded and which rule ids you checked.

Claude Code reads `CLAUDE.md`, which points here, so one file serves every agent.
