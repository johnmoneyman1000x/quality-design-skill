# Glossary

One term per thing. Use these in UI copy, code names and docs.

| Term | Means | Avoid |
| ---- | ----- | ----- |
| Project | a body of work with an owner, a due date and tasks | board, initiative, space |
| Task | one thing to do inside a project, with one assignee | ticket, item, to-do |
| Member | a person in the workspace | user, seat, teammate, collaborator |
| Workspace | the company account that holds projects and members | org, team, account, tenant |

## Rules of use

- Capitalize the four terms in UI copy only when they start a sentence or a label
- Count with the term: "3 tasks", never "3 items"
- An action names its object: "New task", not "Create"
