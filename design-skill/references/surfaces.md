# Surfaces

Each screen has one job and one primary action. Anything that does not serve the job belongs elsewhere.

## Projects

- Job: see which projects need attention today
- Primary: New project
- Shape: a flat list of rows with hairlines, sorted by due date (see `../exemplars/project-list-no-cards.md`)
- Not here: task-level detail, activity history

## Project detail

- Job: move one project forward by assigning and finishing tasks
- Primary: New task
- Shape: header with the project name and owner, tabs for Tasks, Members and Files, tasks as rows
- Not here: workspace settings, other projects' activity

## Activity

- Job: catch up on what changed since you last looked
- Primary: none. Mark all as read is a secondary action
- Shape: one line per change, newest first, unread marked with a blue dot, detail behind a chevron
- Not here: editing tasks inline

## Settings

- Job: change who is in the workspace and how it behaves
- Primary: Save, shown only when something changed
- Shape: sections parted by hairlines and semibold headings, never cards
- Not here: per-project settings, which live in Project detail
